# ⚽ Voetbal voor twee

Een simpel voetbalspel voor twee spelers op één laptop, in een bovenaanzicht.

## Starten

1. Zet `index.html` in een map.
2. Dubbelklik op `index.html`. Het opent in je browser (Chrome, Firefox, Edge of Safari).
3. Druk op een toets om te beginnen.

Je hebt geen internet of extra software nodig.

## Besturing

| Speler | Toetsen |
|--------|---------|
| Blauw  | `W` `A` `S` `D` |
| Rood   | Pijltjestoetsen `↑` `←` `↓` `→` |
| Opnieuw beginnen | `R` |

## Spelregels

- Duw de bal in het doel van de tegenstander.
- Blauw valt het doel rechts aan, Rood het doel links.
- De eerste met 5 doelpunten wint.
- Na elk doelpunt beginnen beide spelers weer op hun startplek.

## Aanpassen

Alles zit in `index.html`. Bovenin het script staan de instellingen:

- `WIN` is het aantal doelpunten om te winnen.
- `GH` is de hoogte van het doel.
- `PR` en `BR` zijn de grootte van de spelers en de bal.
